Software que simula o chaveamento da copa do mundo, é possivel gerenciar os resultados dos jogos até a final e determinar o vencedor.
Desenvolvi um software de gerenciamento/chaveamento da Copa do Mundo de 2022 utilizando Java com Programação Orientada a Objetos (POO). O sistema foi estruturado com camadas bem definidas, empregando o padrão DAO para acesso e manipulação dos dados de seleções, jogadores, técnicos, árbitros, grupos e partidas.

Implementei um pré-set automático responsável por inicializar todas as seleções, distribuir jogadores e técnicos, formar os grupos da fase inicial e gerar as partidas da fase de grupos de forma automática, incluindo datas, horários, estádios e árbitros. Também foi implementada a lógica de atualização de resultados, cálculo de pontuação, saldo de gols e critérios básicos de classificação.

Para a interface gráfica, utilizei JavaFX com FXML, separando a lógica de controle da camada visual, o que facilitou a organização do código e a manutenção do sistema.
